# Renogy RBT210LFP51S-12 BMS firmware kit

Everything learned while reverse-engineering and patching the Renogy RBT210LFP51S-12 BMS firmware
V137.4.5, and how it works alongside the Wakespeed WS500 / Renogy APS-500 alternator regulator on
RV-C. Bring your own stock firmware from Renogy's update package; this repository contains none.

See [`docs/`](docs/).

**Unofficial.** Not affiliated with or endorsed by Renogy or Wakespeed. Modifying and flashing battery
firmware can damage equipment or disable protection. You use this entirely at your own risk.
